## Featured projects

### [Pochta](https://github.com/Morfiuskz/Pochta)

A privacy-focused desktop email client that connects directly to mail providers.

- Multiple accounts, unified inbox, IMAP/SMTP, attachments, and local full-text search.
- OAuth support for selected providers, with manual configuration as a fallback.
- Local SQLite cache, system credential storage, sanitized HTML, and remote images blocked by default.

`Tauri` `Rust` `React` `TypeScript` `SQLite` `OAuth 2.0`

### AI-AssistantZ · Private project

A local personal assistant that combines private LLM inference with knowledge and productivity tools.

- Streaming conversations and history using local models through Ollama.
- Obsidian note search, reading, and creation with confirmation before data-changing actions.
- Voice input through whisper.cpp and FFmpeg, plus web search and external data tools.

`Ollama` `Local LLMs` `Qwen` `Obsidian` `whisper.cpp` `FFmpeg`

A system for finding, analyzing, deduplicating, and qualifying potential business leads.

- Automated website analysis and rule-based lead qualification.
- Optional local LLM analysis through Ollama.

`Node.js` `NestJS` `PostgreSQL` `Prisma` `Ollama` `Overpass API`

### Zaidika · Private project

A Telegram-first SaaS application for appointment-based small businesses.

`Node.js` `NestJS` `React` `TypeScript` `PostgreSQL` `Prisma` `Telegram Bot API` `Docker`
